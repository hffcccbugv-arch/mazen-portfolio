# Mazen Rashad portfolio

Personal portfolio of Mazen Mohamed Rashad, second-year Software Engineering student, Suez Canal University, Ismailia, Egypt.

Static site: open `index.html` in a browser. No build step.

## Contents
- `index.html` - the page (hero, about, skills, projects, contact).
- `assets/styles.css` - the stylesheet, copied from the published site.
- `projects/section-2-practice/` - HTML practice page (Section 2) and its source view.
- `projects/assignment-02/` - Assignment 2 page, source view and table task.

## Provenance
The original Lovable project source was not available, so this folder is a reconstruction of the published site at https://mazenrashadportfolio.lovable.app (HTML, CSS and project pages copied from what the site serves). Changes against the published version: footer Arabic name typo fixed, a Contact section with LinkedIn and GitHub links, university and city wording in the hero and About, a coursework row, and a page description. The coursework pages in `projects/` are unchanged.
